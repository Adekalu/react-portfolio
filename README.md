# Portfolio

React portfolio with React Router, project filtering (state), a validated contact form, and a dark/light toggle.

## Run it
    npm install
    npm start

Opens at http://localhost:3000. Build for production with `npm run build`.

## Customise
Edit the name, `INITIAL_PROJECTS`, `SKILLS` and social links in `src/App.js`, and the page title in `public/index.html`.
